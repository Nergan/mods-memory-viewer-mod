# Mods Memory Viewer

Клиентский мод для Minecraft 1.21.1, Fabric и NeoForge. Показывает, сколько кучи JVM приходится на классы из jar каждого мода.

Это отдельный мод. У MemoryCatcher лицензия All Rights Reserved и нет публичного исходника, поэтому порт сюда не входит.

Экран читает гистограмму классов HotSpot (`gcClassHistogram`) и складывает байты живых экземпляров. Класс относится к моду, если `.class` лежит в jar этого мода или во вложенном jar в `META-INF/jars`. Классы вне jar модов попадают в строку **Minecraft и библиотеки**. Сгенерированный класс вроде `Foo$$Lambda` считается вместе с `Foo`, если этот класс есть в jar мода. Гистограмма останавливает игру: она снимается при открытии экрана, по клавише R и по кнопке «Обновить», а не каждый тик. Нативная память и буферы вне кучи сюда не входят. Строка кучи над списком — это куча JVM (занято, выделено, предел), она не обязана совпасть с суммой гистограммы.

## Как открыть

Клавиша по умолчанию не назначена и не забирает ванильную. Назначьте **Открыть Mods Memory Viewer** в настройках управления, категория Mods Memory Viewer, или выполните клиентскую команду `/modsmemory`. Запуск для разработки с `-Dmodsmemoryviewer.open=true` один раз открывает экран на заглавном меню.

## Загрузчики

| Страница | Нужно |
| --- | --- |
| NeoForge 1.21.1 | `modsmemoryviewer-neoforge-1.21.1-1.0.0.jar` и Kotlin for Forge 5.8.0 |
| Fabric 1.21.1 | `modsmemoryviewer-fabric-1.21.1-1.0.0.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20` |

У Fabric в `fabric.mod.json` стоит `environment: client`: выделенный сервер Fabric этот мод не загружает. Выделенный сервер NeoForge jar загрузить может: он пишет в лог, что замер делается на клиенте, и экран не открывает.
