# Mods Memory Viewer

Клиентский мод для Minecraft 1.21.1 и 26.3, Fabric и NeoForge. Показывает, сколько кучи JVM приходится на классы из jar каждого мода.

Это отдельный мод. У MemoryCatcher лицензия All Rights Reserved и нет публичного исходника, поэтому порт сюда не входит.

Экран читает гистограмму классов HotSpot (`gcClassHistogram`) и складывает байты живых экземпляров. Класс относится к моду, если `.class` лежит в jar этого мода. Вложенный jar в `META-INF/jars` относится к вложенному моду, если Fabric показывает его отдельным модом; иначе он остаётся у родителя. Классы вне jar модов попадают в строку **Minecraft и библиотеки**. Сгенерированный класс вроде `Foo$$Lambda` считается вместе с `Foo`, если этот класс есть в jar мода. Гистограмма останавливает игру: она снимается при открытии экрана, по клавише R и по кнопке «Обновить», а не каждый тик. Справа у таблицы есть скроллбар, который двигается курсором. Нативная память и буферы вне кучи сюда не входят. Строка кучи над таблицей — это куча JVM (занято, выделено, предел), она не обязана совпасть с суммой строк.

## Как открыть

В главном меню откройте **Mods** и зайдите в настройки этого мода. Это единственный способ открыть таблицу. На экране моды, которые загружены сейчас: сверху самый тяжёлый. В строке имя мода, память в МиБ и доля этой строки от измеренной суммы.

Крестик справа сверху закрывает экран. Esc тоже закрывает. Ползунок скроллбара можно тащить курсором, клик по дорожке перематывает к этому месту. Колёсико по-прежнему листает.

## Загрузчики

| Страница | Нужно |
| --- | --- |
| NeoForge 1.21.1 | `modsmemoryviewer-neoforge-1.21.1-1.0.3.jar` и Kotlin for Forge 5.8.0 |
| Fabric 1.21.1 | `modsmemoryviewer-fabric-1.21.1-1.0.3.jar`, Fabric API `0.116.17+1.21.1`, Fabric Language Kotlin `1.13.2+kotlin.2.1.20`, Mod Menu 11.0.4 |
| NeoForge 26.3 | `modsmemoryviewer-neoforge-26.3-1.0.3.jar` и Kotlin for Forge 6.4.0 |
| Fabric 26.3 | `modsmemoryviewer-fabric-26.3-1.0.3.jar`, Fabric API `0.162.0+26.3`, Fabric Language Kotlin `1.14.2+kotlin.2.4.21`, Mod Menu 21.0.0 |

У Fabric в `fabric.mod.json` стоит `environment: client`: выделенный сервер Fabric этот мод не загружает. Выделенный сервер NeoForge jar загрузить может: он пишет в лог, что замер делается на клиенте, и экран не открывает. В `neoforge.mods.toml` для 21.1 нет флага «только клиент»; кнопка Mods регистрируется, когда игра запущена как клиент.
