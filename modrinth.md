Client mod for Minecraft 1.21.1. It sums the HotSpot class histogram by the mod jar that contains each class, including jars nested in `META-INF/jars`. Classes outside mod jars are listed as Minecraft and libraries.

The key starts unbound. Open the screen with `/modsmemory` or bind **Open Mods Memory Viewer**. Refresh runs the histogram again and can stall the game for a moment. This does not measure native memory.

Fabric loads it on the client only. On NeoForge the same jar can sit on a dedicated server and does nothing there.

This is an original mod under MPL-2.0. It is not a port of MemoryCatcher.
